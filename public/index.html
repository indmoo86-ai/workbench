Remote desktop (optional)

When you click the remote desktop button on a device card, the local Home creates a dedicated SSH tunnel and opens the Windows App; then click the saved server connection in the App. The server's RDP can keep listening on localhost only.

The remote host needs Node.js 22.16+, npm and Git. Connecting installs the Worker and starts a background process; model accounts must still be signed in on that device. A local machine connects to the same Home through a local Worker.

Token Usage
